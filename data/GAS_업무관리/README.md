# 내 업무 관리 웹 (Google Apps Script)

기록은 Google 시트, 파일 · 사진은 Google 드라이브 「업무관리_파일」 폴더에 저장합니다.

## 설치

1. 새 Google 시트 만들기 → **확장 프로그램 → Apps Script**
2. `Code.gs` 내용을 전부 지우고 이 폴더의 `Code.gs` 붙여 넣기
3. 왼쪽 **파일 +** → **HTML** → 이름 `Index` → `Index.html` 내용 붙여 넣기 → 저장
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **나만** (「모든 사용자」로 두지 않기)
5. 배포 → **액세스 승인** → 계정 선택 → 「고급」 → 「(프로젝트 이름)(으)로 이동」 → 허용
   - 내가 만든 스크립트라서 뜨는 경고입니다
6. 웹 앱 URL 열기 → 즐겨찾기

## 고친 뒤

코드를 고치면 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 해야 웹 앱에 반영됩니다.

## 주의

- 실습에는 회사 실데이터를 넣지 않습니다
- 10MB 이하 파일만 올립니다
- 다른 사람에게 공유하려면 액세스 설정과 데이터 노출 범위를 사내 기준으로 먼저 확인합니다
