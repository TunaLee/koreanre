실습 2 · 지침
# 주간업무보고 지침

## 입력
- 「팀 업무 현황」 시트: 업무명 · 담당 · 마감일 · 진행률 · 비고
- 「실습용 팀 일정」 캘린더: 이번 주 일정

## 작성 규칙
1. 업무마다 [업무명 · 담당 · 진행률 · 다음 조치] 4항목으로 쓴다
2. 마감일이 지난 업무는 맨 위에 두고 「마감 N일 초과」를 붙인다
3. 진행률이 비어 있으면 추정하지 않고 「확인 요청」으로 쓴다
4. 시트와 일정에 없는 내용은 만들지 않는다

## 출력 형식
- 첫 줄: 이번 주 요약 한 문장
- 표: 업무명 | 담당 | 진행률 | 다음 조치 | 비고
- 마지막: 이번 주 주요 일정 목록 (날짜순)
- 참고자료 「작성예시」의 문체를 따른다
  • 새 대화에서 지침 전체를 붙여 넣고
  • 참고자료 주간보고_양식.docx · 작성예시.docx 첨부
  • 마지막 줄에 「이번 주 보고서 써 줘」
비교①과 나란히 놓고 차이 확인

① 대화로 스킬 만들기

실습 3 · 〈 〉만 내 업무로
내 업무 스킬을 만들고 싶어. 아래 내용으로 스킬을 만들어 줘.
모르는 부분은 나에게 하나씩 물어봐 줘.

- 업무: 〈예: 매주 월요일 부서 경비 집계 보고〉
- 입력 자료: 〈예: 경비 내역 시트 · 항목 · 금액 · 사용일〉
- 작성 규칙: 〈예: 항목별 합계 · 예산 초과 항목은 맨 위〉
- 출력 형식: 〈예: 요약 한 줄 + 표 + 초과 항목 설명〉
- 하지 말 것: 〈예: 시트에 없는 금액을 만들지 않기〉
- 이 스킬을 부를 때 쓸 말: 〈예: 「경비 집계해 줘」 「이번 주 경비 보고」〉

  • 되묻는 질문에 답하기
  • 만들어진 지침을 읽고 저장
